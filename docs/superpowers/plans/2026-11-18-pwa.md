# PWA básica: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** que la app se pueda instalar en el celular, abra rápido, avise versiones nuevas y avise cuando no hay conexión, sin guardar nunca respuestas de `/api`.

**Architecture:** `vite-plugin-pwa` 2.x (Workbox, `generateSW`, `registerType: 'prompt'`) en `client/`. La configuración de la PWA vive en un módulo propio (`client/pwa.config.js`) para poder testearla sin compilar. Un componente React muestra el cartel de versión nueva y el de sin conexión. La API ya sirve el front (`server/src/front.js`); solo se agregan tests de los encabezados de `sw.js` y del manifiesto.

**Tech Stack:** Vite 8, React 19, Tailwind 4, vite-plugin-pwa 2.0.x, workbox-window, Vitest (nuevo en `client/`), Express 5 + supertest (server).

**Spec:** `docs/superpowers/specs/2026-11-18-pwa-design.md`

## Global Constraints

- Textos de la UI en español rioplatense (voseo).
- El service worker nunca guarda ni intercepta `/api` (ni precache, ni runtimeCaching, ni navigateFallback).
- Nunca se recarga la página sola: la versión nueva se aplica solo al tocar "Actualizar".
- Service worker apagado en `npm run dev`.
- Versiones exactas (`--save-exact`) para las dependencias nuevas.
- Sin commits hasta que Diego los pida (regla del proyecto): los pasos "Commit" de abajo se juntan en un commit al final, cuando Diego dé el OK.
- Correr los tests de server desde `C:\dev\sapsa-app\server` (C mayúscula).

## Review Focus

- Un `/api/...` que se abre como navegación (por ejemplo `/api/pecuaria/exportar` en una pestaña) tiene que llegar a la API, no a `index.html` del caché → test en Task 1 (`navigateFallbackDenylist`).
- Un usuario con la app abierta durante un deploy: no se le recarga sola; ve el cartel → test en Task 1 (`registerType: 'prompt'`, sin `skipWaiting`/`clientsClaim` automáticos) + prueba manual Task 3.
- `sw.js` servido con caché larga dejaría a un celular en una versión vieja → test en Task 2.
- Se corta la señal a mitad de uso: aparece "Sin conexión" y desaparece al volver → prueba manual Task 3 (modo avión).
- CSP de helmet bloqueando el manifiesto o el service worker → test en Task 2 + consola sin errores en Task 3.

```js
import { describe, expect, it } from 'vitest';
import { pwaOptions } from './pwa.config.js';

describe('pwaOptions', () => {
  it('pide permiso para actualizar (nunca recarga sola)', () => {
    expect(pwaOptions.registerType).toBe('prompt');
    expect(pwaOptions.workbox.skipWaiting).not.toBe(true);
    expect(pwaOptions.workbox.clientsClaim).not.toBe(true);
  });
  it('no toca /api', () => {
    const deny = pwaOptions.workbox.navigateFallbackDenylist;
    expect(deny.some((re) => re.test('/api/pecuaria/potreros'))).toBe(true);
    expect(deny.some((re) => re.test('/api'))).toBe(true);
    expect(deny.some((re) => re.test('/pecuaria'))).toBe(false);
    expect(pwaOptions.workbox.runtimeCaching ?? []).toEqual([]);
  });
  it('apagada en desarrollo', () => {
    expect(pwaOptions.devOptions?.enabled ?? false).toBe(false);
  });
  it('manifiesto de SAPSA', () => {
    const m = pwaOptions.manifest;
    expect(m).toMatchObject({ name: 'SAPSA', short_name: 'SAPSA', lang: 'es-UY', display: 'standalone', start_url: '/', theme_color: '#18181b', background_color: '#18181b' });
    expect(m.icons.map((i) => i.sizes)).toEqual(expect.arrayContaining(['192x192', '512x512']));
    expect(m.icons.some((i) => i.purpose === 'maskable')).toBe(true);
  });
});
```
